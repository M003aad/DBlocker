# Security Policy

## Supported Versions

| Version | Supported | Notes |
|---|---|---|
| 1.0.x | Yes | Current release line. |
| < 1.0.0 | No | Unsupported and not maintained. |

## Reporting a Vulnerability

Please report security issues privately and responsibly.

Preferred channels:

- GitHub Private Vulnerability Reporting for this repository
- Email: `188705139+M003aad@users.noreply.github.com`

When reporting, include:

- a clear description of the issue;
- steps to reproduce or a proof of concept;
- the affected version;
- any suggested mitigation or fix.

## Response Expectations

- Acknowledgment: within 48 hours of a valid report.
- Initial assessment: within 7 days.
- Target fix timeline: depends on severity and complexity, with a best-effort update to the reporter during triage.

Please do not open public issues for vulnerabilities. Public disclosure should wait until a fix is available or a coordinated release is ready.
